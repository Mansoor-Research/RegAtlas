================================================================================
README: Supplementary Data and Tables Data Dictionary
================================================================================
Manuscript: RegAtlas: A Learning-to-Rank Multi-Omics Framework for Post-GWAS Locus-to-Gene Mapping in Psychiatric Disorders

This file contains the data dictionary for the Supplementary Tables and Data files (.csv) generated by the RegAtlas framework. These files contain the raw feature matrices, cross-validation metrics, and final schizophrenia (SCZ) locus-to-gene mappings.

--------------------------------------------------------------------------------
1. TRAINING UNIVERSE & SCHIZOPHRENIA RANKINGS 
--------------------------------------------------------------------------------
Files: 
- Table_S1_Training_Universe.csv (Dataset A / Supplementary Data S1)
- Table_S3_SCZ_Rankings.csv (Dataset B / Supplementary Table S1 / Data S2)

These files contain locus-gene pairs with the following column headers:

[Locus & Gene Identifiers]
locus_id                        : Unique identifier for the GWAS locus.
chrom                           : Chromosome containing the sentinel variant.
sentinel_rsid                   : The dbSNP rsID for the sentinel GWAS variant.
sentinel_pos                    : Genomic coordinate (GRCh38) of the sentinel variant.
gwas_pval                       : P-value of the sentinel variant from the GWAS summary statistics.
gwas_beta                       : Effect size (beta) of the sentinel variant from the GWAS summary statistics.
gene_id                         : Ensembl Gene ID.
gene_name                       : HGNC Gene Symbol.
gene_biotype                    : Biotype of the candidate gene (e.g., protein_coding, lncRNA).

[Labels & Model Outputs]
label                           : (Training only) Binary truth label (1 = Causal, 0 = Competitor).
confidence                      : (Training only) Confidence tier from Open Targets L2G gold standard.
label_set                       : (Training only) Source of the label (e.g., ot_platform, otg_original).
regatlas_rank                   : (SCZ only) Final predicted rank of the candidate gene within the locus (1 = top predicted gene).
regatlas_score                  : (SCZ only) Raw LambdaRank prediction score output by the model.

[Spatial Features]
abs_tss_distance                : Absolute linear distance (in base pairs) from the sentinel variant to the gene's Transcription Start Site (TSS).
tss_distance_rank               : Rank of the gene based on TSS distance within the locus (1 = nearest).
is_nearest_tss                  : Binary indicator (1/0) if the gene is the nearest gene to the sentinel variant.

[Molecular Features (GTEx & ENCODE)]
has_any_brain_eqtl              : Binary indicator (1/0) if a significant cis-eQTL exists in GTEx Brain tissues.
brain_eqtl_max_slope            : Maximum absolute eQTL effect size (slope) across Brain Cortex and BA9.
brain_eqtl_max_neg_log10_pval   : Maximum significance (-log10 P-value) of the eQTL association.
has_re2g_link                   : Binary indicator (1/0) if an ENCODE-rE2G enhancer link is predicted.
re2g_max_score                  : Maximum ENCODE-rE2G prediction score linking the locus to the gene.
re2g_total_elements             : Total number of discrete enhancer elements linking to the gene promoter.
has_both_eqtl_and_re2g          : Binary indicator (1/0) if both eQTL and rE2G evidence are present.


--------------------------------------------------------------------------------
2. FEATURE ABLATION & BENCHMARK METRICS
--------------------------------------------------------------------------------
File: Table_S2_Ablation_and_Baselines.csv (Supplementary Table S2)

Contains model performance metrics across cross-validation folds:

Model_Configuration             : The specific feature modality, combination, or baseline method being evaluated.
Num_Features                    : The number of features included in the model configuration.
Top1_Accuracy_Pct               : Percentage of loci where the true causal gene is ranked exactly at position 1.
Recall_at_3_Pct                 : Percentage of loci where the true causal gene is ranked within the top 3.
Recall_at_5_Pct                 : Percentage of loci where the true causal gene is ranked within the top 5.
MRR                             : Mean Reciprocal Rank (1/Rank of the true causal gene, averaged across loci).
NDCG_at_5                       : Normalized Discounted Cumulative Gain at rank 5, measuring the quality of the top-5 ranking.


--------------------------------------------------------------------------------
3. FUNCTIONAL PATHWAY ENRICHMENT
--------------------------------------------------------------------------------
Sheet: Table S3 - Pathway Enrichment (in Supplementary_Tables.xlsx)

Contains downstream Gene Ontology (g:Profiler) functional enrichment metrics:

Ontology_Source                 : Gene Ontology domain (GO:BP = Biological Process, GO:MF = Molecular Function).
Term_ID                         : Native Gene Ontology accession ID.
Term_Name                       : Gene Ontology term description.
Top1_Count                      : Number of Top-1 prioritized genes annotated to this term.
Query_Size                      : Total number of evaluated protein-coding Top-1 genes (97).
Term_Background_Count           : Number of background candidate genes annotated to this term.
Background_Size                 : Total protein-coding candidate background size (1,708).
Fold_Enrichment                 : Relative fold enrichment: (Top1_Count/Query_Size) / (Term_Background_Count/Background_Size).
FDR_q_value                     : Benjamini-Hochberg false discovery rate adjusted P-value.
Enriched_Genes                  : RegAtlas Top-1 prioritized genes belonging to this functional term.
